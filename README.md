# CVQKD-Reconciliation based on Arithmetic Reconciliation

More details are described in https://arxiv.org/abs/2602.05526.

Arithmetic Reconciliation presents an alternative to Multi-Dimensional Reconciliation and Slice-Error-Correction, aiming to reduce computational cost of Reconciliation Step in Gaussian CV-QKD protocols.
Some simulations where performed, showing that the reconciliation efficiency obtained by the technique is acceptable, especially at SNR regimes lower than 0 dB.
